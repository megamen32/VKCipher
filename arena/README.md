# VKEncrypt Adversarial Arena

Локальная «критик-креатор» система для выбора формата шифротекста до его переноса в userscript.

- **Creator** маскирует уже готовые байты `IV || AES-256-GCM(ciphertext, tag)` и обязан восстановить их без потерь.
- **Critic** не получает ключей и оценивает вероятность того, что сообщение создано VKEncrypt.
- **Referee** независимо проверяет AES-GCM round-trip, ограничения транспорта VK, overhead и качество обнаружения на отдельной blind-выборке.

## Быстрый запуск

```bash
npm run arena
npm run arena -- --rounds=500
npm run arena -- --json
npm run arena:inspect -- --plain "Проверочное сообщение"
npm run test:arena
```

Инструкция для безопасного прогона через OpenAI-compatible LLM endpoint и
обновления тестов: [`LLM_TESTING.md`](LLM_TESTING.md).

Для консервативной разметки слов запускайте `node arena/classify-dictionary.js`.
Скрипт сохраняет только JSON-разметку, а ключ читает из `LLM_API_KEY`.

Начальный creator использует emoji без видимого префикса. Это рабочий transport baseline, а не обещание скрытности: начальный critic должен уверенно находить длинные равномерные emoji-последовательности.

## Как запустить двух агентов

1. Откройте две независимые Codex-сессии в этом репозитории.
2. Первому агенту передайте [`creator/AGENT.md`](creator/AGENT.md), второму — [`critic/AGENT.md`](critic/AGENT.md).
3. Агенты меняют только собственный `submission.js`. Общие файлы арены принадлежат referee.
4. После хода creator запустите `npm run arena -- --json`; затем дайте critic один ответный ход.
5. Не выбирайте победителя по одному прогону. Финальный referee меняет seed/corpus и запускает не менее 1000 blind-раундов.

## Что считается реальным ограничением VK

Арена использует консервативный текстовый профиль:

- не более 4096 Unicode code points;
- не более 4096 UTF-16 units, поэтому surrogate-pair emoji стоят две единицы;
- корректный NFC Unicode без unpaired surrogate;
- запрещены zero-width и управляющие символы;
- моделируются нормализация `CRLF → LF`, NFC и удаление пробелов по краям;
- отдельный Playwright-тест моделирует рендер emoji как `<img alt="…">`, который встречается в DOM VK.

Это не эмулятор серверной антиспам-системы VK. Метрики измеряют обнаруживаемость локальным классификатором и устойчивость к наблюдаемым преобразованиям web-клиента.

## Метрики

- `Round-trip`: доля сообщений, которые после транспорта проходят AES-GCM и совпадают с исходным текстом.
- `VK transport pass`: доля сообщений, прошедших ограничения referee.
- `Average UTF-16 expansion`: число единиц VK-сообщения на один code point открытого текста.
- `ROC-AUC`: насколько critic разделяет обычные и защищённые сообщения независимо от порога.
- `Creator score`: stealth + компактность, умноженные на надёжность и transport pass.
- `Critic score`: нормализованный AUC, где случайное угадывание даёт `0`, идеальное обнаружение — `100`.

Правила соревнования описаны в [`REFEREE.md`](REFEREE.md).
